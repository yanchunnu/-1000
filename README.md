## 제작 및 음원 기록

글자별 그림 16개는 AI로 새로 생성했습니다. 한자와 병음, 훈음, 직역과 풀이는 PDF에서 실제 글자로 조판했습니다.

낭독은 이 저장소의 기존 `index.html`에 있던 HeyGen 합성 음원을 재사용했습니다. 중국어 음원은 기존 커밋 `8994b51fe0d6b7def56449462c249979250bf9a1`에서 宿의 발음을 xiù로 수정한 버전입니다. 개별 음원은 원본 파일을 변환하지 않고 실제 형식인 MP3 확장자로 보관했습니다. 이어 듣기 파일은 한국어 뒤에 약 1.2초 쉼을 넣고 중국어를 연결했습니다. 개별 음원 길이는 한국어 약 5.98초, 중국어 약 8.54초입니다.

기존 원격 음원 URL에 의존하지 않고 파일을 이 저장소에 직접 보관합니다. 합성 음원의 실제 발음에 대한 원어민 청취 감수는 별도로 권장합니다.
