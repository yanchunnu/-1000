# 그림과 소리로 배우는 천자문 250구

- 학습 페이지: https://yanchunnu.github.io/-1000/
- 이어 배우기 시작: https://yanchunnu.github.io/-1000/?lesson=2
- 제1~250구 전체 교재: [63쪽 PDF](cheonjamun-001-250.pdf)
- 제5~250구 이어지는 교재: [62쪽 PDF](cheonjamun-005-250.pdf)

A4 세로, 한 쪽에 4구씩 배치했습니다. 마지막 쪽은 제249~250구와 복습 활동입니다. 각 글자의 병음, 정자, 한글 음, 뜻 연상 그림, 뜻과 함께 구절별 독음·간체자·직역·풀이가 들어 있습니다. 250구의 한자 1,000자가 빠짐없이 서로 다른 글자로 구성되었는지 확인했습니다.

교재의 QR은 한국어·중국어 1,000자 전체 낭독 영역으로 연결됩니다. 해당 쪽의 단원도 함께 선택됩니다. 학습 페이지에서 63개 단원을 고르고 한국어·중국어 낭독을 각각 들을 수 있습니다. 0.5~1.5배속, 반복, 처음부터 듣기, 이전·다음 단원 기능을 제공합니다.

## 음원 파일

`audio/lesson-01-ko.mp3`부터 `audio/lesson-63-ko.mp3`까지 한국어 63개, 같은 번호의 `-zh.mp3` 중국어 63개를 저장했습니다. 제1과 한국어는 기존 녹음을 재사용했습니다. 중국어 제1과를 포함한 모든 중국어 단원은 Shuxian으로 통일했습니다. 새 음성은 HeyGen Starfish로 합성했습니다. 한국어는 Divya, 중국어는 Shuxian 목소리입니다. 개별 파일의 재생·디코딩과 생성 길이 및 제공된 타임스탬프를 검사했습니다. 전체 원어민 청취 감수는 실시하지 않았습니다.

한자음은 사전의 기본 음과 두음법칙을 반영한 구절 독음이 다를 수 있습니다. 중국어는 현대 표준중국어 병음을 표시했으며, 宿 xiù·說 yuè·禪 shàn·屬 zhǔ·任 rén 등 문맥에 따른 읽기를 반영했습니다. 일부 합성 입력에 동음자를 사용했지만 교재와 화면에는 원래 한자를 표시합니다. `audio-manifest.json`은 파일별 길이와 검증 기록입니다.

## 본문과 그림

원문은 周興嗣의 《千字文》입니다. 한국에서 널리 읽는 女慕貞烈·玉出崑岡 등의 자형을 사용했습니다. 구절 풀이와 직역은 이 교재를 위해 새로 작성했습니다. 삽화는 AI로 제작한 뜻 연상용 학습 그림이며, 인물과 추상 개념은 상징 장면으로 표현했습니다.

## 1,000자 전체 낭독

- [한국어 전체 낭독](audio/full-ko.mp3)
- [중국어 전체 낭독](audio/full-zh.mp3)

각 언어의 63개 단원 음원을 제1~250구 순서로 연결했습니다. 속도와 음높이는 그대로이며 단원 사이에 0.18초 쉼을 넣었습니다. 전체 음원도 페이지의 재생속도·반복·일시정지·처음부터 듣기 설정을 사용할 수 있습니다. `full-audio-manifest.json`에는 단원별 시작·종료 시점과 원본 해시가 있습니다. 중국어 첫 단원에서 宿의 별자리 독음 xiù를 위해 합성 입력에는 동음자 秀를 사용했으며, 교재와 화면은 원문 宿를 유지합니다.
